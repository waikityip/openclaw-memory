# RICS PFM — 英國皇家特許測量師設施管理專業

## 項目目標

探索並規劃取得英國皇家特許測量師學會 (RICS) 設施管理專業 (PFM - Professional Facilities Management) 資格嘅路徑。

## 關於 RICS

RICS (Royal Institution of Chartered Surveyors) 係全球最大嘅測量、地產、建造同環境相關專業機構，1881年於英國成立。RICS 會員資格被全球認可，代表專業標準同誠信。

## 關於 PFM 專業

設施管理專業 (Professional Facilities Management) 涵蓋：

- 設施策略規劃 (Facilities Strategy)
- 物業組合管理 (Property Portfolio Management)
- 建築運營同維護 (Building Operations & Maintenance)
- 空間管理 (Space Management)
- 可持續發展同 ESG (Sustainability & ESG)
- 智能建築同 PropTech 整合

## Andrew 嘅目標

- 申請成為 **MRICS (PFM)** 特許測量師

## 申請路徑

RICS 提供多種成為 MRICS 嘅途徑：

### 路徑一: APC (Assessment of Professional Competence)
- 適合：相關學位 + 工作經驗
- 需通過：初審 → 案例研究 → 面試

### 路徑二: Senior Professional
- 適合：豐富工作經驗（通常10年+）
- 需證明：專業領導能力同貢獻

### 路徑三: Academic
- 適合：學術界專業人士

## 待研究項目

- [ ] 學歷要求同豁免政策
- [ ] APC 詳細流程同時間表
- [ ] 強制能力要求 (Mandatory Competencies)
- [ ] 技術能力要求 (Technical Competencies)
- [ ] 案例研究 (Case Study) 要求
- [ ] 面試準備 (Final Assessment Interview)
- [ ] CPD (持續專業發展) 要求
- [ ] 與 HKIS PFMD 的互認安排（如有）
