## APC 基本要求

### 1. 會籍級別

| 級別 | 資格 | 描述 |
|------|------|------|
| **Student** | 學生 | 就讀認可課程 |
| **Probationer** | 試用會員 | 開始 APC 培訓期 |
| **Associate Member** | 副會員 | 技術級別 |
| **Member (MHKIS)** | ⭐ 專業會員 | 目標資格 |
| **Fellow (FHKIS)** | 資深會員 | 傑出貢獻 |

**注意：** Probationer 會籍通常限 8 年，必須在此期間完成 APC。

### 2. 培訓期要求

| 學歷背景 | 最短培訓期 | 工作天數 |
|----------|-----------|----------|
| **認可測量學學位** (Accredited Degree) | 2年 | ≥450 天 |
| **非認可但相關學位** | 3年 | ≥675 天 |
| **非相關學位 + 12個月相關工作經驗** | 3年 | ≥675 天 |
| **副會員 (AMHKIS)** 申請 | 3年 | ≥675 天 |

**年齡要求：** 申請 APC 時必須年滿 21 歲

## APC 評核組成部分

```
┌─────────────────────────────────────────────────────────────┐
│                    APC 流程總覽                              │
├─────────────────────────────────────────────────────────────┤
│  1. 入門申請 (APC1/PFM)                                      │
│     ↓                                                        │
│  2. 實務培訓 (Log Book + SAR)                                │
│     ↓ 每9個月提交一次自我評估報告                             │
│  3. 結構化學習 (PQSL - 每年≥20小時)                          │
│     ↓                                                        │
│  4. 實務任務 (Practical Task / Part II)                      │
│     ↓                                                        │
│  5. 最終面試 (Final Assessment Interview)                    │
│     ↓                                                        │
│  6. 成為 MHKIS (PFMD)                                        │
└─────────────────────────────────────────────────────────────┘
```

### 詳細組成部分

| # | 組成部分 | 說明 | 頻率/時限 |
|---|----------|------|-----------|
| 1 | **Log Book** (培訓日誌) | 按時間順序記錄實務培訓同學習經驗 | 持續記錄 |
| 2 | **SAR** (Self Assessment Report) | 自我評估報告，每9個月總結培訓進度 | 每9個月提交 |
| 3 | **PQSL** (Pre-qualification Structured Learning) | 結構化學習，每年最少20小時 | 每年≥20小時 |
| 4 | **Practical Task** | 真實工作任務評核 | 培訓期完成後 |
| 5 | **Final Assessment** | 最終面試評核 | 通過實務任務後12個月內 |

## 重要時間規定

### 申請時限

| 項目 | 時限要求 | 逾期後果 |
|------|----------|----------|
| **入門申請 (APC1)** | 入職後1個月內提交 | 培訓期由提交日開始計算 |
| **換工作申請 (APC1S)** | 轉工後1個月內提交 | 培訓期暫停，提交日才恢復 |
| **SAR 提交** | 每9個月結束後盡快提交 | 延長培訓期，影響後續評核 |
| **實務任務申請** | 完成培訓期後24個月內 | 超過24個月不接受申請 |
| **最終面試申請** | 通過實務任務後12個月內 | 超過12個月不接受申請 |

### 失敗後重新申請

| 情況 | 重新申請條件 |
|------|--------------|
| **實務任務失敗** | 額外培訓≥9個月 + 補充 SAR |
| **最終面試失敗** | 額外培訓≥9個月 + 補充 SAR + 持續學習 |
| **時限** | 必須在失敗後24個月內重新申請 |

## 導師 (Counsellor) 要求

- 必須係合資格測量師（HKIS 企業會員）
- 負責指導同評估候選人表現
- 候選人應每3個月與導師檢討培訓進度
- 所有申請表格必須由導師簽署

## Andrew 嘅情況初步分析

| 項目 | Andrew 背景 | 初步評估 |
|------|-------------|----------|
| **學歷** | BEng (應該係非認可測量學學位) | 可能需要3年培訓期 |
| **工作經驗** | 現於 HKHS 任 PropTech Manager | 相關工作經驗有優勢 |
| **專業資格** | MIMechE, CEng | 已有工程師資格，專業基礎穩固 |

2. 確認最短培訓期（2年或3年）
3. 尋找合資格 PFMD Counsellor
4. 提交 APC1/PFM 入門申請
