# HKIS PFMD — 香港測量師學會物業設施管理組

## 項目目標

探索並規劃取得香港測量師學會 (HKIS) 物業設施管理組 (PFMD) 專業會員資格嘅路徑。

## 關於 HKIS PFMD

香港測量師學會 (The Hong Kong Institute of Surveyors) 係香港唯一具備特許測量師專業資格認授權嘅機構。物業設施管理組 (Property and Facility Management Division, PFMD) 專注於：

- 物業資產管理 (Property Asset Management)
- 設施管理 (Facility Management)
- 空間規劃同管理
- 建築物維護同保養策略
- 物業相關財務管理
