# PFMD 培訓日誌 (Log Book) 指南

## 什麼是 Log Book？

Log Book 係 HKIS PFMD APC 嘅核心文件，用於**按時間順序**記錄你喺培訓期間獲得嘅實務經驗同學習成果。佢係：

- 實務培訓嘅**分析式記錄**
- 自我評估報告 (SAR) 嘅基礎
- 最終面試時評核員參考嘅重要文件

---

## 日常記錄指引

### 每日記錄要素

| 欄位 | 內容 | 示例 |
|------|------|------|
| **日期** | 工作日日期 | 2026-03-24 |
| **項目/工作** | 簡短描述工作內容 | 審查大廈年度維修預算 |
| **核心能力** | 對應 PFMD 核心能力 | A3 - 財務管理 |
| **詳情** | 具體工作內容 | 評估升降機更換工程報價 |
| **學習成果** | 學到什麼 | 了解升降機工程成本結構 |
| **反思** | 個人反思 | 需要加深對供應商談判技巧 |

### 記錄頻率建議

| 時間 | 行動 |
|------|------|
| **每日** | 簡短記錄主要工作 (建議用工作日誌) |
| **每週** | 整理一週經驗，提煉學習點 |
| **每月** | 檢視能力進度，調整學習重點 |
| **每3個月** | 與導師正式檢討，獲取反饋 |
| **每9個月** | 整理 SAR，提交給導師批閱 |

## 核心能力對應技巧

### 如何對應核心能力

每次記錄工作時，標記涉及嘅核心能力代碼：

```
示例記錄：
────────────────────────────────────────────
日期：2026-03-24
項目：參與大廈外牆維修工程招標

核心能力：
├── B3 (建築維護) - 主要
├── C1 (建築技術) - 次要  
└── C2 (建築法例) - 次要

詳情：
協助審查外牆維修工程標書，包括：
- 評估維修範圍同方法
- 核實承包商資格
- 檢查合規要求 (MWIS, BD)

學習成果：
✓ 了解強制驗樓計劃要求
✓ 學習評估維修標書要點

反思：
需要進一步了解外牆維修嘅技術細節，
計劃參加相關 CPD 課程。
────────────────────────────────────────────
```

## 自我評估報告 (SAR) 撰寫指南

### SAR 是什麼？

SAR (Self Assessment Report) 係每 **9個月** 提交一次嘅正式報告，總結培訓期間嘅學習同進度。

### SAR 結構

| 部分 | 內容 | 頁數建議 |
|------|------|----------|
| **1. 培訓概覽** | 培訓期、工作性質、導師資料 | 1頁 |
| **2. 工作經驗總結** | 主要項目同經驗 | 2-3頁 |
| **3. 核心能力進度** | 各項能力嘅發展 | 3-4頁 |
| **4. 結構化學習** | PQSL 活動記錄 | 1-2頁 |
| **5. 反思同計劃** | 自我反思同下一階段計劃 | 1頁 |
| **6. 導師評語** | 導師簽署同評語 | 1頁 |

### SAR 撰寫技巧

**DO (應該做)：**
- ✅ 用具體例子說明經驗
- ✅ 量化成果（如適用）
- ✅ 誠實反映能力差距
- ✅ 展示反思同改進
- ✅ 按核心能力分類經驗

**DON'T (不應該做)：**
- ❌ 只列出工作職責
- ❌ 空泛描述（如「學到很多」）
- ❌ 忽略失敗或挑戰
- ❌ 抄襲他人經驗
- ❌ 提交前無導師批閱

## 結構化學習 (PQSL) 記錄

### PQSL 要求

| 項目 | 要求 |
|------|------|
| **每年時數** | 最少 20 小時 |
| **自學上限** | 每年最多 5 小時 |
| **結構化學習** | 每年最少 15 小時 |

### PQSL 類別比例

| 類別 | 比例 | 說明 |
|------|------|------|
| **HKIS 舉辦嘅 CPD** | ≥50% | PFMD 研討會、學會活動 |
| **其他專業機構 CPD** | ≤25% | RICS、IFMA 等 |
| **高等教育/培訓課程** | ≤25% | 大學課程、專業培訓 |
| **自學** | ≤25% | 閱讀、網上學習 |

### PQSL 記錄格式

```
┌─────────────────────────────────────────────────────┐
│ PQSL 記錄範例                                        │
├─────────────────────────────────────────────────────┤
│ 日期：2026-02-15                                     │
│ 活動：PFMD 年度研討會 - 智能建築管理                  │
│ 主辦：HKIS PFMD                                      │
│ 時數：3 小時                                         │
│ 相關能力：B1, B4, D1                                 │
│ 學習摘要：                                           │
│ 了解 IoT 設備管理、BIM 設施應用、智能維護系統        │
│ 反思：                                               │
│ 計劃研究如何喺 HKHS 引入智能設施管理方案             │
└─────────────────────────────────────────────────────┘
```

## Log Book 常見錯誤

### 記錄方面
| 錯誤 | 正確做法 |
|------|----------|
| 臨時抱佛腳記錄 | 每日/每週持續記錄 |
| 流水賬式描述 | 聚焦學習成果同反思 |
| 忽略「軟技能」 | 記錄溝通、管理、解難經驗 |
| 無能力對應 | 每項經驗標記相關核心能力 |

### SAR 方面
| 錯誤 | 正確做法 |
|------|----------|
| 逾期提交 | 設定提醒，預留時間撰寫 |
| 無導師批閱 | 提前安排導師會議 |
| 缺乏量化 | 使用數據說明成果 |
| 忽視失敗經驗 | 坦誠討論挑戰同學習 |
